About this preview

Standalone interaction proposal, using sample records. No backend, real agent, source access or TEST integration.

Try the complete flow

  1. Inspect calibration.txt in Summary. Type in the footer and send.
  2. Conversation shows your message and an illustrative reply. Return to Summary resumes the inspection and reading position.
  3. Search across the Magnet, filter by type, inspect a result and return to results.
  4. Open the header gear for source and collection settings.
  5. In Perspectives, create a question without a title; discuss it in the same footer.

Boundaries

Factual Summary describes sample records. Evidence-grounded answers and synthesis are unavailable until agent access is verified as restricted to selected sources. Illustrative replies do not read the collection. An evidence context carries its reference only. Naming, renaming and question history are browser-local proposals. A Perspective may eventually become a full Conversation; that action is not implemented.

State and keyboard

Enter sends, Shift+Enter inserts a line, Ctrl/⌘+Enter sends, Alt+Enter records only. The split button chooses the action for one message. Escape dismisses the current layer and retains drafts. Creation, per-Perspective revision, rename and message drafts have separate slots. Cancel discards only the active editor draft. Tabs, search, inspection, history, scroll positions, draft and settings persist locally. Reset affects this demo only. The puck moves by dragging or arrow keys on desktop.

Settings demonstrates supported Conversation/post and text-file capture with proposed future adapters. Collection is simulated. Saving settings neither collects nor erases old copies. Text files are bounded to the first 64 KiB; links do not acquire targets. Preview fixtures includes an empty collection. Focused browser checks are not screen-reader certification.
