## Who removes what

| Name below | What it means |
|---|---|
| **Forward** | Rust answers the route, and Python's handler stays for what Rust returns `NotOwned` on. A route's rollback (`contracts/route-table.md`) also needs the handler. Removable once Rust forwards none of that route's cases and the owner has accepted that release. |
| **R5.2** | Source reads and the shared scan. |
| **R7 Posts** | The "Posts and responses" write family (`routes.md`). |
| **R7 Dispatch** | The "Dispatch and runs, last and together" family. It also ends Quick Ask and unknown-grant forwarding at `/api/worker`. |
| **R8** | Python leaves. |
| **No package** | The plan names nobody. See "Forward cases no package owns". |

## Forward cases no package owns

Python can't retire these routes until Rust answers these cases, and no package in `R4-R8-reconcile.md` is given them. At the latest, R8 has to settle them, because Python is gone then and a forward has nowhere to go.

- `/fluid/api/search`: non-ASCII search text.
- `/fluid/api/document`: unreadable files, and locators with no valid digest.
- `/fluid/api/object-refs`: more than 64 references, extraction engine failures, non-text fields.
- `find` and `/api/references?q=`: a matching Turn with a fill block.
