# P1.0: what runs that isn't a route

Read at `b8e324c`, from `web/__init__.py`'s `serve` and by sweeping `mentis/` for threads, timers, subprocesses, module and instance registries, and file writes. Routes are in [`routes.md`](routes.md). The search method is stated in section H, with what it can't see.

**Columns.** *Release:* when Rust owns it (R7's family named). *When its process dies:* what is lost and what recovers, for the process it lives in, which is Python unless it says otherwise. *Deletion point:* when Python's code goes. "R7 last" is dispatch and runs, together. Every Python deletion is also subject to the plan's rule: no remaining caller, and the commit follows the owner's acceptance of that release on DAY-TO-DAY.

**A front crash or restart touches none of this:** the front holds no registry of Python's and shares no process. Its effect on an agent's calls, and so possibly on a run's outcome, is in `docs/rust-front-restart.md`. Sections A to F are what a **Python** death costs, unless they say otherwise. It ends live runs either way, which is why any Python restart is the owner's decision each time (Turn #1025).

## H. How this was searched, and what it can't see

Grepped across `mentis/*.py`: `threading.Thread`, `Timer`, `ThreadPoolExecutor`, `asyncio` task creation, `atexit`, `signal`, `subprocess`, module-level and `self._x` containers and locks, `threading.local`, `global`, `lru_cache`, `time.sleep`, timed waits, `Event`, and file writes (`os.replace`, `write_text`, `open(..., "w")`, `mkdir`, `shutil`). Read `serve` and `main` whole.
