⚠ Accept before Unrestricted Host

Unrestricted host execution runs the agent directly on this computer as your user, without its runtime's sandbox and not in a container. The agent may technically access files outside its workspace, local credentials, network services and local processes. Mentis still checks every Mentis operation against the run's grant, and your Permission Mode is recorded, but a runtime that does not ask in this mode does not enforce it.
